# 📊 Target vs Achievement Sales Analysis | Excel Project

## 📌 Project Overview

This project focuses on analysing sales performance by comparing sales targets with actual achievements across different regions, states, products, sales managers, and sales executives.

The objective is to evaluate business performance, identify sales gaps, monitor target achievement, and generate meaningful insights that can support data-driven business decisions.

## 🎯 Project Objectives

- Analyse overall sales targets and actual achievements.
- Measure target achievement percentage.
- Identify sales performance gaps and shortfalls.
- Compare regional and product-wise sales performance.
- Evaluate sales performance across different states.
- Monitor sales manager and sales executive performance.
- Generate actionable business insights through Excel reporting.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- SUMIFS Function
- Excel Formulas
- Data Analysis
- Data Reporting
- Data Visualization

## 📂 Dataset Overview

The dataset contains 200 sales records with the following information:

- Region
- State
- Branch
- Product
- Sales Manager
- Sales Executive
- Sales Target
- Actual Sales
- Variance
- Achievement Percentage

**Dataset Structure:**
- 4 Regions
- 20 States
- 53 Branches
- 10 Products
- 13 Sales Managers
- 20 Sales Executives

## 📈 Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Sales Target | ₹16.41 Crore |
| Actual Sales | ₹15.64 Crore |
| Achievement Percentage | 95.29% |
| Target Shortfall | ₹77.26 Lakh |
| Total Sales Records | 200 |

## 🔍 Key Business Insights

1. **Overall Performance:** The business achieved 95.29% of its total sales target, indicating a shortfall of approximately ₹77.26 lakh.

2. **Regional Performance:** East recorded the highest target achievement at 96.89%, while West recorded the lowest at 94.02%.

3. **Product Performance:** Printers achieved the highest target achievement percentage at 99.26%.

4. **Improvement Opportunity:** Tablets recorded the lowest achievement at 89.24%, highlighting an area that requires additional attention.

5. **Business Performance:** The analysis helps identify performance gaps and areas where sales improvement strategies may be required.
